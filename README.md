# 刻印快速筛选分解小助手

这是独立于爬塔项目的本地版本仓库。`src/` 是可恢复的程序输入；早期核心模块仅存有 Python 3.11 字节码，升级前请保留这些 `.pyc` 文件。Git 标签 `v2.0` 保存升级前源码和 EXE。旧 EXE 运行时还需要对应发布目录中的 `_internal/` 依赖。

v2.1 界面：自动/手动双色开关，常驻统计和当前刻印图标，保留提醒，错误时保存过程日志。F9 开始，F10 停止。游戏操作与识别逻辑没有在此版本修改，请在真实窗口验证。

在现有 Windows Python 环境中运行 `build.ps1` 可重新构建。发布目录必须保留 EXE 和 `_internal/`；`logs/` 由程序运行时创建。

本仓库尚未选择开源许可证；不能仅凭界面署名代码限制他人修改。
